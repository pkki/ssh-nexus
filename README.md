# SSH Nexus

Tera Termの代替を目指した、Windows向けのタブ／分割対応SSHクライアントです。

## 主な機能

- SSH・ターミナル・ネットワーク接続を表現した専用Windowsアプリアイコン
- 日本語・英語・中国語（簡体字）・韓国語・スペイン語・フランス語・ドイツ語・ポルトガル語（ブラジル）の8言語UI
- 初回はWindows表示言語を自動判定し、設定画面からいつでも固定言語／自動判定を切り替え可能（アプリメニューも連動）
- 登録済みSSH接続を起動直後に一覧表示
- パスワード／秘密鍵での自動ログイン
- ランダムな256-bitマスターキーとAES-256-GCMで保管庫全体を暗号化（接続メタデータ、認証情報、known hosts、ワークスペース、設定を含む）
- Windows Hello（Windows PIN・顔・指紋）で通常の保管庫解除
- scrypt（N=131072）で保護された16文字以上の緊急用回復パスフレーズ
- VS Code風の複数タブ（操作ボタンとタブを上下2段に分離、横スクロール対応）
- タブを約0.35秒長押しし、Windowsスナップ風に左・右・上・下半分へ配置（既存の未接続ペインを整理して常に単純な2画面にし、別タブは接続を維持したまま移動）
- byobu／tmux／vim／topなどの全画面TUIへ、接続開始時から正しいPTYサイズを同期
- 接続先クリック時は専用タブを即時作成し、接続進捗を表示
- 横分割・縦分割・入れ子分割・ドラッグでサイズ変更
- SHA-256ホスト鍵のTOFU確認と、変更時の接続ブロック
- 接続先ごとに調整可能なSSH keepalive、xterm-256color、日本語UTF-8表示
- SFTPファイルブラウザー（アップロード・ダウンロード・作成・削除）
- ローカルのファイル／フォルダをSFTPパネルまたは任意のリモートフォルダへドラッグ＆ドロップして一括アップロード
- クリック可能なパンくずナビゲーション、名前／サイズ／更新日ソート、項目数・合計サイズ表示、常時表示の操作メニュー
- ローカルポートフォワード（複数同時、動的ポート対応）
- セッションログ保存、標準／カスタム定型コマンド、一斉入力
- Ed25519・RSA・ECDSA SSH鍵ペア生成
- SFTPリモートテキストエディター
- お気に入り・最近使った順・自動再接続
- ローカル／リモートポートフォワード、SOCKS5動的プロキシ
- 接続・再接続時に自動開始するポート転送プロファイル（最大20件）
- 暗号化保管庫バックアップ／復元、信頼済みホスト鍵管理
- 最大5段の多段踏み台サーバー（ProxyJump／Bastion）チェーン、循環参照防止
- タブ・分割・接続先をまとめたワークスペース保存／復元
- Linuxサーバー監視ダッシュボード（メモリ・ディスク・プロセス・Docker）
- 複数SSHセッションへの一括コマンド実行
- ターミナル内検索、SFTP転送進捗
- コマンドパレット、正式なWindowsアプリメニュー、タブ並べ替え
- SSH Agent認証・Agent転送、keyboard-interactive／TOTP二要素認証
- UTF-8・Shift_JIS（CP932）・EUC-JPターミナル文字コード

## Windows Helloと回復パスフレーズ

Windowsは、セキュリティ上の理由からアプリにWindows PINそのものを渡しません。本アプリはWindows標準のWindows Hello画面でPIN／顔／指紋を検証し、現在のWindowsユーザーにDPAPIで紐付けたランダムな保管庫マスターキーを使用します。アプリがWindows PINを保存・読み取り・独自検証することはありません。

WindowsアカウントやHelloを利用できない場合に備え、初回に16文字以上の回復パスフレーズを設定します。これは短い数字PINではなく、scryptで強化した鍵暗号化鍵としてのみ使われます。旧形式の保管庫は旧PINを一度だけ入力し、暗号化バックアップを作成したうえで完全暗号化形式へ強制移行します。

Windows Hello確認とDPAPIは同一Windowsユーザーの保護境界を利用します。そのため、ログイン済みユーザー権限を奪ったマルウェアに対する完全な防御を意味するものではありません。

## 起動

Node.js 22.12以降をインストールした環境で:

```powershell
npm install
npm start
```

## Windowsインストーラー作成

Windows上ではelectron-builder標準のNSISターゲットを使用します。

```powershell
npm run build:win
```

Linuxからクロスビルドする場合は、Wineを必要としない同梱NSISスクリプトを使用できます。

```bash
npx electron-builder --win dir
npm run build:installer:linux
```

`release/SSH-Nexus-Setup-<version>.exe` が作成されます。インストーラーはユーザー単位で管理者権限を要求せず、インストール先選択、デスクトップ／スタートメニューのショートカット、Windows「インストールされているアプリ」への登録、`sshnexus://`プロトコル、アンインストールに対応します。アンインストール時も保管庫・設定・録画は削除しません。

## 操作

- 左下の **Add** で接続先を登録
- 一覧を左クリックすると接続
- 一覧を右クリックすると編集
- **+ Tab** で新規タブ
- **Split H / Split V** で選択中ペインを分割
- ペイン右上の **×** で閉じる
- **Lock** で全SSH接続を切り、保管庫をロック

初めて接続するホストではSHA-256ホスト鍵が表示されます。サーバー管理者から聞いたフィンガープリントと照合してから信頼してください。登録済みホスト鍵が変わった場合は、MITM攻撃の可能性があるため自動的にブロックします。

接続先編集画面の自動ポート転送は、1行につき次の形式で指定します。待受ポートには `0`（自動割当）も使用できます。

```text
L 127.0.0.1:5000 127.0.0.1:8080
R 127.0.0.1:9000 127.0.0.1:3000
D 127.0.0.1:1080
```

`L` はローカル転送、`R` はリモート転送、`D` はSOCKS5です。

## 録画と再生

録画停止時に、AES-256-GCMで暗号化された `.ssnrec` を既定の `ドキュメント/SSH Nexus/Recordings` へ自動保存します。設定画面から保存先を変更・表示できます。**再生**を押すと、保管庫解除中だけ録画一覧を復号して再生または削除できます。以前の平文録画は一覧表示またはセキュリティ移行時に暗号化形式へ変換され、取り込んだ録画も再暗号化されます。接続切断、エラー、タブやペインを閉じた場合も録画中なら自動保存します。録画形式v2ではPTYの初期列・行数と途中のサイズ変更も記録し、再生画面ではFitAddonによる再整形を行わず元のグリッドを維持するため、byobu／tmuxなどのステータス行も崩さず再現します。

## 外部から接続画面を開く

```text
sshnexus://connect?host=server.example.com&user=alice&port=22
SSH Nexus.exe --connect alice@server.example.com:22
```

外部要求は接続確認画面へホスト・ユーザー・ポートを入力するだけで、自動接続しません。URL内のパスワードは受け取らず、保管庫がロック中なら解除後まで要求を保留します。多重起動時は既存ウィンドウへ安全に転送されます。

## OpenSSH config移行

`HostName`、`User`、`Port`、`IdentityFile`、`ProxyJump`、`Compression`、`ConnectTimeout`、`ServerAliveInterval`、`ServerAliveCountMax`、`ForwardAgent`、`Host *` の既定値を解析します。カンマ区切りの多段 `ProxyJump` はSSH Nexusの踏み台チェーンへ変換します。ワイルドカードだけの接続先は登録せず、重複するユーザー・ホスト・ポートはスキップします。秘密鍵のパスはメモとして移行しますが、秘密鍵やパスワードは明示的な操作なしに読み込みません。

## セキュリティ設計

- 保管庫: ランダムな32-byteマスターキーによるAES-256-GCMの全ペイロード認証付き暗号化
- 暗号化対象: 接続先名・ホスト・ユーザー名・メモ・認証情報・known hosts・カスタム定型文・設定・ワークスペース・復元スナップショット
- 回復鍵導出: 16文字以上の回復パスフレーズ + scrypt（N=131072、r=8、p=1、ランダム32-byte salt）。導出鍵でマスターキーをラップ
- Windows連携: Windows Hello `UserConsentVerifier` + Electron `safeStorage`（WindowsではDPAPI）によるマスターキー保護
- 録画と監査: 用途を暗号学的に分離したAES-256-GCMエンベロープ。旧平文ファイルは移行後に削除
- Renderer: `nodeIntegration: false`、`contextIsolation: true`、制限付きCSP、ナビゲーション／新規ウィンドウ／権限要求の制限
- SSHホスト認証: 暗号化保管庫内のSHA-256 known-host fingerprint pinning
- 暗号方式: ssh2実行環境が実際に対応する安全な既定アルゴリズムから自動ネゴシエーション（未対応方式を強制しない）
- ロック／終了時: SSHセッション切断、メモリ上の保管庫キーを上書きして破棄

監査ログの明示的な書き出し、セッションログ保存、OpenSSH config書き出しなど、ユーザーが保存先を選んで要求したエクスポートは相互運用のため平文です。アプリ内部の自動永続化データは暗号化されます。平文エクスポートは保存先のアクセス権と取り扱いに注意してください。

### 注意

Windowsユーザーとして既にログインした状態で高度なマルウェアが同一ユーザー権限を完全に奪った場合、どのデスクトップアプリも絶対安全ではありません。BitLocker、Windows Update、Microsoft Defender、画面ロック、SSH鍵＋パスフレーズの併用を推奨します。

SSH Agent転送は、接続先からさらに別のSSHサーバーへ接続する場合だけ有効にしてください。接続先が侵害されていると、接続中に転送済みAgentが悪用される可能性があります。
